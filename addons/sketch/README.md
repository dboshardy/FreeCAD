# CADApp Sketch

Add-on for FreeCAD, Phase 1 (2D sketcher): a circle tangent to existing curves, stretch, conflict diagnosis that names
the constraint whose removal fixes the sketch, and closed-region detection with highlight (nested loops).
Works on FreeCAD's Sketcher objects; adds commands, changes none of its files.

Not affiliated with the FreeCAD Project. Install and test as in `../template/README.md`; test: `FreeCADCmd -t TestSketch`.
