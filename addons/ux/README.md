Add-on for FreeCAD: command palette (`Ctrl+Shift+P`). Radial menu, hotkey strip and context hotkeys follow (design doc §5 Phase 0).
Not affiliated with the FreeCAD Project. Install and test as in `../template/README.md`; test: `FreeCADCmd -t TestUx`.
