# CADApp Body Tools

Add-on for FreeCAD, Phase 2 (parametric part modeling): parameters from a JSON file, variants of one part
(values, suppression, properties), thin-wall extrude, rib, variable-radius fillet, fill-pattern geometry,
draft / curvature / interference / wall-thickness inspection, and a history strip with a movable marker.
Works on PartDesign, Spreadsheet and Part objects; changes none of their files.

Not affiliated with the FreeCAD Project. Install and test as in `../template/README.md`;
test: `FreeCADCmd -t TestBodyTools`, GUI: `addons/ci/run_tests.py addons/bodytools TestBodyToolsGui --gui`.
