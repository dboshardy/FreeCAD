# Contributing

By contributing you attest that your work is original or under a compatible licence
and that you did not copy code from GPL-only, commercial or unlicensed projects
(design doc §12 R20). Sign off every commit (`git commit -s`).

Run `python3 check.py` and `python3 -m unittest discover tests` before sending a change.
Inside stock FreeCAD: `FreeCADCmd -t TestSketch` with this folder on the module path.
