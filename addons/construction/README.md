# CADApp Construction

Add-on for FreeCAD: cabinets, wall, floor, roof and deck framing, stairs, slabs, sheds, woodworking builds
with joinery, cut lists, lumber and sheet plans, drawings, advisory checks. Members, stairs, slabs, sheet
layouts and guards are BIM workbench objects (Arch_Structure, Arch_Stairs, Arch_Panel_Sheet, Arch_Fence)
with the lumber, rules and quantities added on top. Tutorials: `Tutorials/` (the Tutorials command).

Not affiliated with the FreeCAD Project. Install and test as in `../template/README.md`;
tests: `FreeCADCmd -t TestConstruction`, `-t TestConstructionApp`, `FreeCAD -t TestConstructionGui`.
